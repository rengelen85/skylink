# SkyLink Airways - Hackathon Starter Dataset

Synthetic data for the *Intelligent Operations Resource Management* challenge. Everything is generated by `skylink_generator.py` (deterministic, seed 2026), so it can be re-created or scaled.

**Reference date:** Monday 2026-10-26 (08:26 UTC). All timestamps are UTC. The IATA winter season W26/27 started 2026-10-25.

## Formats

- `csv/` all tables (UTF-8, header row, empty = NULL; pipe `|` separates list values)
- `json/` same tables as pretty-printed JSON arrays (2-space indent, tables up to 60k rows) + `hubs_nested.json` (hub > facilities, fleet, headcount), `contractors.json` (nested skills), `scenarios.json` (what-if library)

## Scale (matches the brief)

- 650 aircraft (7 types), 15 hubs, ~1,200 flights/day, exactly 45,000 employees (3,888 pilots, 8,047 cabin crew, 23,665 ground staff, 7,000 engineers, 2,400 ops coordinators) + 1,900 contractors

## Key relationships

```
employees.home_hub -> airports.airport_iata
employee_skills.(employee_id, skill_id) -> employees, skills
flights.aircraft_tail -> aircraft.tail_number ; flights.aircraft_type -> aircraft_types
flights.(origin|destination|crew_base_hub) -> airports ; flights.dep_gate_id -> airport_gates.gate_id
flight_crew_assignments.(flight_id, employee_id) -> flights, employees (employee_id NULL when UNFILLED)
availability_events.employee_id -> employees ; training_enrollments.(session_id, employee_id) -> training_sessions, employees
maintenance_activities.(tail_number, facility_id) -> aircraft, maintenance_facilities
maintenance_requirements.activity_id -> maintenance_activities ; maintenance_assignments.(activity_id, requirement_id, employee_id)
disruption_flight_impacts.(disruption_id, flight_id) -> disruptions, flights ; new_route_requirements.route_launch_id -> new_route_launches
```

## How to derive supply and demand

- **Demand per flight**: `aircraft_types.min_cabin_crew`, pilots 2 (3 if block >= 8 h), plus `service_requirements` for ground turnaround. Required skills: type rating for the flight's family, `CC_SEP` + `CQ_NARROW/WIDE` for cabin crew.
- **Supply**: `employees.monthly_capacity_hours` (pilots/cabin = flight hours, others = productive hours) minus approved `availability_events`. A skill with `status = EXPIRED` (or expiring before the flight date) makes the person ineligible.
- **Utilization** history is in `monthly_operations_history`; the baseline for forecasting is `network_plan_monthly` and the seasonal index in `calendar`.

## Stories deliberately planted in the data

- **Understaffed**: Rome (FCO) cabin crew (~100% utilization), Athens (ATH) ground staff (>120%), Barcelona (BCN) pilots (~93%), Paris (CDG) ops coordinators (~97%), Madrid (MAD) engineers.
- **Spare capacity**: Warsaw (WAW) pilots (~65%), Stockholm (ARN) ground staff (~59%), Lisbon (LIS) cabin crew.
- **Seasonality**: summer 2027 is ~22% above the annual baseline (`seasonal_index` 1.22 in Jul-Aug; planned flights are ~45% above Nov-Feb); pending (not yet approved) vacations pile up for Jul-Aug 2027, so approved supply looks better than it will be. Flu season raises sickness in Nov-Feb.
- **Disruptions**: fog at ZRH today, Storm Aurelia on AMS/FRA/CPH 29-30 Oct (severe at AMS), French ATC strike 12 Nov, snow in ARN/CPH 17 Nov, Italian ground-handling strike 20 Nov.
- **Aircraft**: 12 AOG aircraft and ~22 in heavy maintenance right now; 100 deferred defects due within 4 weeks.
- **Compliance**: ~3,000 expired and ~11,500 expiring-within-60-days skills; ~1,900 renewals have no training session yet. 125 flight crew slots and 50 maintenance slots are UNFILLED, mostly pilots at MAD, LIS and ARN.
- **Expansion**: 8 new routes (launching from 28 Mar 2027) and 3 candidate hubs, for the forecasting and what-if questions.

## Simplifications and caveats (tell the teams)

- Data is synthetic. Names, events and figures are illustrative; flight patterns do not mirror any real airline's schedule.
- Aircraft rotations are plausible but not guaranteed feasible (about 377 flights start from an airport where the planned tail is not positioned). Crew positioning is ignored; crews are assigned from the flight's crew base hub.
- Flight crew rosters cover only the first 14 days; flights in days 15-28 have demand but no assignments by design.
- Regulatory rules are simplified and not legal advice. Flight hour caps in `monthly_capacity_hours` are planning values.
- `TR_CONV`, `MX_TYPE` and `PURSER` training sessions have no enrolments yet (open capacity for scenario work).
- Ground staff and engineers have no per-flight assignments. Use shift pattern, capacity hours and absences for availability.

## Example questions to try

```sql
-- Which hubs have the highest pilot utilization last month?
SELECT hub, utilization_pct FROM monthly_operations_history WHERE role='Pilot' AND month='2026-09' ORDER BY utilization_pct DESC;

-- Flights with unfilled crew slots in the next 7 days
SELECT f.flight_id, f.origin, f.destination, a.slot FROM flight_crew_assignments a JOIN flights f USING(flight_id) WHERE a.status='UNFILLED' AND f.operating_date < '2026-11-02';

-- Engineers certified for A350 maintenance (B1 + type endorsement) at AMS
SELECT e.employee_id FROM employees e JOIN employee_skills s1 ON s1.employee_id=e.employee_id AND s1.skill_id='MC_B1' JOIN employee_skills s2 ON s2.employee_id=e.employee_id AND s2.skill_id='MT_A350' WHERE e.home_hub='AMS' AND s1.status!='EXPIRED';
```
